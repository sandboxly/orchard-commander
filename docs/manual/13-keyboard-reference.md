# Keyboard reference

On macOS, ⌘ is Command, ⌥ is Option, ⇧ is Shift and ⌃ is Control. On Mac
keyboards, the function keys may require **fn**.

## Panels

| Action | macOS | Windows / Linux |
| --- | --- | --- |
| Move the cursor | ↑ ↓ Page Up Page Down | ↑ ↓ Page Up Page Down |
| First / last entry | Home / End (fn+← / fn+→) | Home / End |
| Jump to a name | Type its first letters | Type its first letters |
| Open a folder or archive; open a file | Enter | Enter |
| Open with the default application | Shift+Enter or ⌘Enter | Shift+Enter or Ctrl+Enter |
| Parent folder | Backspace | Backspace |
| Switch to the other side | Tab | Tab |
| Reload both panels | ⌘R | Ctrl+R |
| Show or hide hidden files | ⇧⌘. | Ctrl+Shift+. or Ctrl+H |
| Go to a folder or server address | ⌘G | Ctrl+G |
| Choose a location for the left / right panel | ⌥F1 / ⌥F2 | Alt+F1 / Alt+F2 |
| Show the active folder in the other panel too | ⌘E | Ctrl+E |
| Exchange the two panels' folders | ⌘U | Ctrl+U |
| Open the folder under the cursor in the left / right panel | ⌘← / ⌘→ | Ctrl+← / Ctrl+→ |

## Marking

| Action | macOS | Windows / Linux |
| --- | --- | --- |
| Mark or unmark, and move down | Space or Insert | Space or Insert |
| Mark or unmark with the mouse | ⌘-click or right-click | Ctrl-click or right-click |
| Mark all | + or ⌘A | + or Ctrl+A |
| Unmark all | - or ⌥⌘A | - or Ctrl+Alt+A |
| Invert marks | * | * |

## File operations

| Action | macOS | Windows / Linux |
| --- | --- | --- |
| Copy | F5 | F5 |
| Move or rename | F6 | F6 |
| Make directory | F7 | F7 |
| Move to trash (delete on servers) | F8, Delete or ⌘⌫ | F8, Delete or Ctrl+Backspace |
| Multi-rename | ⌘M | Ctrl+M |
| Undo the last multi-rename | ⌘Z | Ctrl+Z |

In the **File exists** dialog: **O** Overwrite, **A** Overwrite all,
**S** Skip, **K** Skip all.

## Preview

| Action | Key |
| --- | --- |
| Show or hide the preview on the other side | F3 |
| Next "View as" option | Shift+F3 |

In a PDF preview:

| Action | Key |
| --- | --- |
| Next page | → ↓ Page Down Space, or scroll down |
| Previous page | ← ↑ Page Up Backspace, or scroll up |
| First / last page | Home / End |

In the audio and video player:

| Action | Key |
| --- | --- |
| Play / pause | Space or K |
| Back / forward 5 seconds | ← / → |
| Mute / unmute | M |
| Autoplay on / off | A |

## Finding files

| Action | macOS | Windows / Linux |
| --- | --- | --- |
| Find files | ⌘F or ⌥F7 | Ctrl+F or Alt+F7 |
| Show the last results again | ⇧⌘F | Ctrl+Shift+F |
| Stop a running search | Esc | Esc |

## Bookmarks

| Action | macOS | Windows / Linux |
| --- | --- | --- |
| Bookmark menu | ⌘D | Ctrl+D |
| Search bookmarks | ⌥⌘D | Ctrl+Alt+D |

In the bookmark menu: **+** add the current folder, **-** remove it,
**\*** organize bookmarks.

## Servers

| Action | macOS | Windows / Linux |
| --- | --- | --- |
| Connect to server | ⌘K | Ctrl+K |
| Disconnect the active panel's server | ⇧⌘K | Ctrl+Shift+K |

## Terminal

| Action | macOS | Windows / Linux |
| --- | --- | --- |
| Show the terminal / focus it / hide it | ⌘J or ⌃\` | Ctrl+\` |
| Change the shell to the panel's folder | ⌃⇧\` | Ctrl+Shift+\` |
| Copy / paste in the terminal | ⌘C / ⌘V | Ctrl+Shift+C / Ctrl+Shift+V |

## Window and app

| Action | macOS | Windows / Linux |
| --- | --- | --- |
| Command palette | ⌘P | Ctrl+P |
| Menu bar | F9 | F9 |
| Settings | ⌘, | Ctrl+, |
| Larger / smaller / default font size | ⌘= / ⌘- / ⌘0 | Ctrl+= / Ctrl+- / Ctrl+0 |
| Quit | F10 or ⌘Q | F10 or Ctrl+Q |
