## Conventions

Keyboard shortcuts are given for macOS first, followed by the Windows and
Linux equivalent where it differs, for example **⌘F** / **Ctrl+F**. When only
one key is shown, it is the same on all systems.

On Mac keyboards, the function keys (F1–F12) may require holding **fn**,
depending on your keyboard settings.

Menu commands are written as **Menu → Command**, for example
**Files → Copy**.
