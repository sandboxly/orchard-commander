All your file work in one window

Source and destination sit side by side, so copying or moving takes one keystroke. Previews, archives, servers, batch renaming and a terminal are built in, and you rarely need to open another app.

Same workflow on macOS, Windows and Linux

Orchard Commander looks and behaves the same on all three systems. Shortcuts and layout don't change, so switching between machines doesn't mean relearning anything.

  • macOS
  • Windows
  • Linux

Shortcuts you may already know

Copy, move, rename and search each have their own key, as in classic two-panel file managers. If that style is new to you, the common keys are quick to learn, and the mouse works too.

F3PreviewF4EditF5CopyF6MoveF7MkDirF8TrashF9MenuF10Quit

Tools that save a trip to another app

Previews

Code, Markdown, PDFs, images, audio and video show up in the other panel, including files on a server.

Batch rename

Name files by date, counter or music tags. You see every new name before it's applied and can undo the whole batch.

Archives and servers

Zip, 7z and rar files open like folders. SFTP, SMB, WebDAV and S3 work like your local disk.

Search

Results appear as a folder, so you can preview, select and move them together.

Terminal

It opens below the panels in the current folder and follows along as you browse.

Made for working across systems

Orchard Commander is meant for people who use more than one operating system and want to manage files the same way on each of them. It is free and open source, and the source code is on GitHub.
