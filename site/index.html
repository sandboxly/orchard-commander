Preview

See what's inside before you open it

Switch either side to Preview and it shows whatever the cursor is on in the other panel: syntax-highlighted code, rendered Markdown, images, PDFs page by page, audio with a live spectrum and waveform, and video. Files on servers stream instead of downloading first.

  • Code and text in your color scheme
  • PDF paging with the keyboard or the wheel
  • Hex view for everything else

Find files

Search results you can work with

Search by name with wildcards or regular expressions, by contents, size and date — across folders, servers and inside archives. The hits appear as a folder while the search runs, so you can preview them, mark them all and move them somewhere else in one go.

  • *.py;*.md, report, *.zip|*old*
  • Files containing — or not containing — a phrase
  • Results stay available with ⇧⌘F

Multi-rename

Rename a hundred files as easily as one

Build new names from placeholders — parts of the old name, counters, dates, parent folders — and from file metadata such as music tags, photo dates and video resolution. Every new name is checked before anything happens, and the whole batch can be undone.

  • [=track] [=artist] - [=title]
  • Search and replace with regular expressions
  • Safe swaps and case-only changes

Terminal

A shell that goes where you go

Open a terminal below the panels with ⌘J. Each side has its own shell, and it stays in step with its panel: cd in the terminal and the panel follows; browse in the panel and the shell follows. Full-screen tools like vim, htop and tmux work, mouse included.

  • Your own shell: zsh, bash, fish or PowerShell
  • Prompt themes with Nerd Font icons
  • Panels refresh after every command

Archives & servers

Zip files and servers are just folders

Press Enter on a zip, tar, 7z or rar archive to browse it like a folder — nested archives included — and copy out what you need. Connect to SFTP, SMB, WebDAV and S3 and work there with the same keys as on your own disk. Passwords stay in your system's keychain.

  • SFTP · SMB · WebDAV · S3
  • Bookmarks for local and remote folders
  • Copy between any two locations

Keyboard first

F-keys, marks with Space and +, a command palette on ⌘P. The mouse works too.

Looks like a terminal

A monospace grid, box frames and eight color schemes — or your own. Follows light and dark mode if you like.

Cross-platform

The same app and the same keys on macOS, Windows and Linux.

Open source

MIT licensed, with add-on interfaces for previewers, connection types and rename fields.
