A two-panel file manager for macOS, Windows and Linux

Orchard Commander shows two folders side by side. F5 copies the selected files from one panel to the other, F6 moves them, F7 creates a folder and F8 moves files to the trash. F4 opens a file in the text editor. If you have used Norton Commander or Total Commander, you already know how it works.

Preview

Preview files in the other panel

Press F3 and the other side shows the file under the cursor: source code with syntax highlighting, Markdown, images, PDFs, audio and video. The preview changes as you move through the list. Videos and music on a server start playing while they are still loading.

  • Highlighting follows the app's color scheme
  • Turn PDF pages with the arrow keys or the scroll wheel
  • Files of any other type open in a hex view

Editor

Edit text files with F4

F4 opens the file under the cursor in an editor window with syntax highlighting in the app's color scheme. It works on your disk and on servers: a file in an SFTP panel is read over SFTP and saved back there. ⇧F4 creates a new file in the current folder.

  • Find and replace, go to line, unlimited undo
  • Keeps the file's encoding and line endings, including CRLF
  • Saves to a temporary file first, so a crash can't leave half a file

Find files

Search results open as a folder

Alt+F7 or ⌘F searches by name, content, size and date, on your disk, on servers and inside zip files. Matches appear in the panel as a folder while the search is still running. You can preview them, mark them all with + and move them elsewhere with F6.

  • *.py;*.md finds Python and Markdown files
  • *.zip|*old* finds zip files without “old” in the name
  • Content search can also list the files that lack a phrase

Multi-rename

Rename many files with one pattern

⌘M opens a multi-rename tool that uses Total Commander's placeholders: [N] for the old name, [C] for a counter, [Y]-[M]-[D] for the date. It also reads metadata, such as the artist of an MP3 or the date a photo was taken. You see every new name before you start, and ⌘Z undoes the whole batch.

  • IMG_[C:4] gives IMG_0001.jpg, IMG_0002.jpg and so on
  • [=track] [=artist] - [=title] names songs from their tags
  • Duplicate names are caught before anything is renamed

Terminal

A shell below the panels

⌘J opens your usual shell under the panels: zsh, bash, fish or PowerShell. Each side has its own session. When you type cd, the panel goes to the same folder, and when you change folders in the panel, the shell follows. vim, htop and tmux work, including the mouse.

  • Prompt themes like powerlevel10k keep their icons
  • Files you delete with rm disappear from the panel
  • Esc, Tab and Ctrl+C go to the shell

Archives & servers

Archives and servers open in a panel

Press Enter on a zip, tar, 7z or rar file to look inside, even if it is inside another archive, and copy out what you need. Connections to SFTP, SMB, WebDAV and S3 servers open in a panel and work with the same keys as your disk. Passwords are stored in the system keychain.

  • Bookmarks can point to folders on servers
  • Copy from a server straight into a folder on another server
  • Archives are read-only

Keys and mouse

Most commands have a shortcut, and the command palette on ⌘P finds the ones you forget. You can also do everything with the mouse.

Color schemes

Eight schemes are built in, gruvbox among them, and you can add your own. The app can switch with the system between light and dark.

Three systems

The same app runs on macOS, Windows and Linux. The shortcuts are the same too, with ⌘ in place of Ctrl on a Mac.

Open source

Orchard Commander is MIT licensed. Add-ons can bring new previews, connection types and rename fields.
